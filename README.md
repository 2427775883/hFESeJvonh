# Python健康课程推荐系统简介

## 核心功能
- 用户登录注册
- 健康课程推荐
- 课程详情展示
- 课程评分
- 课程收藏
- 课程排序与搜索
- 评论功能
- 课程数据可视化分析
- 用户管理
- 评分评论偏好管理
- 课程管理

## 适用场景
- 健康课程学习者
- 课程开发者
- 教育机构
- 健康管理平台

## 技术特点
- 使用Django框架构建
- 基于MySQL数据库存储数据
- 前端采用HTML、CSS、JS等技术实现交互
- 支持用户管理与课程管理功能
